# Módulo Molinetes - Frontend

Aplicación en React (Vite) para el monitoreo en tiempo real de los giros por minuto en planta textil.

## Ejecución en Entorno Local

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

## Estrategia de Ramas
Se utiliza **Git Flow** con las ramas permanentes `main` (Producción) y `develop` (Pruebas/QA).
